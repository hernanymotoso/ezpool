# Ezpool - Solana Liquidity Pool Manager

## About The Project

Ezpool is a decentralized application (dApp) built on the Solana blockchain that enables users to manage liquidity pools efficiently. 

### Key Features
- Create and manage liquidity pools
- Interact with Whirlpool protocol (without SDKs, I'm creating my own integrations)
- Real-time pool statistics and monitoring
- User-friendly interface built with Next.js
- Secure wallet integration using Solana Wallet Adapter
